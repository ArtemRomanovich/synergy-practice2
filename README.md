# Учёт сотрудников

**Кейс-задача № 3.** Описать класс с именем `Worker`, содержащий поля:
фамилия и инициалы работника, название занимаемой должности, зарплата,
год поступления на работу.

## Запуск

Требуется node.js

```
node index.js
```

## Запуск тестов

Требуется node.js

```
node test-worker.js
```
## Класс Worker
Назначение: представление данных о работнике и базовые операции над ними.

Свойства: lastNameInitials, position, salary, yearHired.

Основные методы:

create(...) — фабричный метод для создания объекта с данными.

Сеттеры — для безопасного изменения полей.

display() — форматированный вывод информации о работнике.

getExperience() — расчёт стажа.

dispose() — сброс состояния объекта.

Особенности: валидация числовых полей, отсутствие строгой инкапсуляции (можно усилить приватными полями).

Модуль worker.js экспортирует объект { Worker }.

Программа index.js реализует консольный интерфейс, управление списком работников и фильтрацию по стажу.
